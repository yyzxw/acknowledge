## 快速开始

### 添加新项目

1. 在 `docs/` 下创建新项目文件夹，如 `docs/my-project/`
2. 在该文件夹中创建 `index.md`
3. 更新 `mkdocs.yml` 的 `nav` 配置

### 部署

```bash
git add .
git commit -m "Add new project"
git push origin main
```

自动构建并部署，约 1 分钟生效。
